# searchlight.social
#
# WHY THIS FILE EXISTS. Every path on this domain returns 200 with the full page:
# wrangler.jsonc sets not_found_handling: "single-page-application" so /i/{id}
# works without routing code, which means a crawler never meets a 404 and has
# nothing telling it where to stop. Measured 2026-09-05 — /wp-admin, /.env and
# random junk paths all serve the complete home page. This file is the only
# signal a well-behaved crawler gets, and 12,816 pageviews in the domain's first
# month were overwhelmingly probes finding a 200 everywhere they looked.
#
# WHY /i/ AND /e/ ARE CLOSED. They are unlisted invite and event links, shared
# person to person, and a crawler walking them would put group names into search
# results. index.html already ships `noindex, nofollow` by default and only
# relaxes it for the home path, so a crawler that does not render JavaScript can
# never index an invite. This is the other half of that: keep compliant crawlers
# off the paths entirely rather than trusting them to render a meta tag.
#
# The home page, privacy policy and support page are public and meant to be
# found — /privacy and /support are the two URLs App Review opens in a browser.

# AI CRAWLERS. Cloudflare's managed robots.txt used to add this group and was
# turned off on 2026-09-05 because its `User-agent: * / Allow: /` sat above the
# rules below and cancelled the catch-all — two wildcard groups, and on a tie the
# least restrictive wins. Turning it off restored the catch-all and took these
# with it, so they are re-stated here, in the file, where they are versioned and
# testable rather than living in a dashboard toggle.
#
# Content-Signal is the declaration that accompanies them: findable by search,
# not usable as training data.

User-agent: Amazonbot
Disallow: /

Disallow: /

Disallow: /

Disallow: /

Disallow: /

User-agent: Google-Extended
Disallow: /

User-agent: GPTBot
Disallow: /

User-agent: meta-externalagent
Disallow: /

# Everyone else. ONE wildcard group, deliberately. Cloudflare's managed block was
# a SECOND `User-agent: *` carrying `Allow: /`, and a duplicate wildcard is how
# the catch-all below gets cancelled — crawlers that merge groups resolve a tie
# in favour of the least restrictive rule, and crawlers that take the first match
# never reach this one. If anything is ever added here, add it to this group.

User-agent: *
Content-Signal: search=yes, ai-train=no
Disallow: /i/
Disallow: /e/
Allow: /$
Allow: /privacy
Allow: /support
Disallow: /
